## 1. Overview

This repository covers four workshops that build progressively on the CartPole-v1 environment, moving from failure *prediction* to failure *avoidance* and unsupervised *representation learning*.

| Workshop | Topic | Key output |
|---|---|---|
| **W1** | Data preparation & supervised baselines | 3 ML classifiers, EDA notebook |
| **W2** | Deep sequence model (LSTM) | LSTM trained with BCE + AdamW, checkpoint |
| **W3** | Reinforcement learning (DQN) | DQN agent, 6-config hyperparameter sweep |
| **W4** | Autoencoders & VAEs | AE / β-VAE / DAE, anomaly detection, latent analysis |

### Dataset

| Property | Value |
|---|---|
| File | `data/raw/cartpole_dataset.csv` (1.99 MB) |
| Rows / episodes | 35,874 / 400 |
| Columns | `episode, t, x, x_dot, theta, theta_dot, action, label` |
| Class balance | 94.51 % class 0 / 5.49 % class 1 (17.2 : 1) |
| SHA256 | `ec067d5dcc498f2b5c5486d24f290283431ef3a0db0a4952cfde84f07e4f53f8` |

Generated by rolling out CartPole-v1 with a mixed policy (noisy expert + random actions), seeds fixed to 42. A state is labelled `1` if the episode fails within the next five steps (`|theta| > 12°` or `|x| > 2.4 m`).

## 5. Workshop 1 — Data Preparation & Baselines

All commands run from the repository root.

### Verify dataset integrity

```bash
python src/w1/dataset_info.py
```

Prints SHA256 checksum, shape, column types, class counts and episode statistics.

### Create the episode split (already included)

```bash
python src/w1/dataset.py
```

Splits 400 episodes 70/15/15 % (stratified by episode length) and writes `data/splits.json`. The file is committed — never re-split.

### Train and evaluate the three baselines

```bash
python src/w1/baselines.py                # engineered features (main result)
python src/w1/baselines.py --raw-only     # ablation: 5 raw columns only
python src/w1/baselines.py --augment      # ablation: Gaussian-noise augmentation
```

Trains Logistic Regression, Random Forest and Gradient Boosting; selects the decision threshold on validation (max F1); prints test metrics; writes `runs/workshop1/baseline_results_*.csv`.

### Generate report figures

```bash
python src/w1/make_figures.py
```

### Exploratory data analysis (notebook)

```bash
jupyter notebook notebooks/eda.ipynb
```

Covers integrity, target distribution, episode structure, feature statistics, correlations and the split. Google Colab: open `notebooks/eda.ipynb` directly.

## 6. Workshop 2 — Deep Sequence Model (LSTM)

Reuses the same episode split (`data/splits.json`) so metrics are directly comparable with W1.

### Architecture smoke-test

```bash
python src/w2/model.py                              # default: 2-layer LSTM, 64 hidden → 53,569 params
python src/w2/model.py --cell gru --bidirectional   # GRU variant
```

### Train

```bash
python src/w2/train_lstm.py                         # default configuration
python src/w2/train_lstm.py --cell gru --window 16  # GRU variant
python src/w2/train_lstm.py --window 32             # longer context window
python src/w2/train_lstm.py --hidden 128            # wider model
python src/w2/train_lstm.py --augment               # noise augmentation (train only)
```

Builds past-only sliding windows, trains with position-weighted BCE loss (17.2:1 imbalance), AdamW, cosine LR schedule, dropout, weight decay, gradient clipping and early stopping on validation F1. Logs to TensorBoard (`runs/workshop2/tb/`) and CSV. Saves the best checkpoint to `checkpoints/workshop2/model_best.pt`.

```bash
tensorboard --logdir runs/workshop2/tb
```

### Evaluate on the test set

```bash
python src/w2/evaluate_lstm.py
```

Reloads `checkpoints/workshop2/model_best.pt`, reports test metrics and prints the W1-vs-W2 comparison table. Writes `runs/workshop2/eval_*.json` and `runs/workshop2/comparison_*.csv`.

### Verify the saved checkpoint

```bash
python src/w2/test_model.py --n 10 --split test   # 10 predictions on held-out data
python src/w2/test_model.py --interactive          # manual state input
```

### Generate report figures

```bash
python src/w2/make_figures_w2.py
```

Saves `fig2-architecture.png`, `fig2-curves.png`, `fig2-confusion.png`, `fig2-roc-pr.png` and `fig2-comparison.png` to `runs/workshop2/figures/`.

Google Colab: open `notebooks/workshop2_colab.ipynb` and run all cells.

## 7. Workshop 3 — Reinforcement Learning (DQN)

### MDP definition

| Component | Definition |
|---|---|
| State | `(x, ẋ, θ, θ̇)` — 4 continuous values |
| Actions | 0 = push left (−10 N), 1 = push right (+10 N) |
| Transition | Cart-pole equations of motion, Euler step 0.02 s |
| Reward | +1 per step survived + potential-based shaping |
| Termination | `|θ| > 12°` or `|x| > 2.4 m`; truncation at 500 steps |

### Run the full pipeline

```bash
# 1. Validate the Gymnasium environment (random-policy diagnostics)
python src/w3/env.py

# 2. Rebuild the W1 classifier as a controller (self-test)
python src/w3/w1_bridge.py

# 3. Hyperparameter sweep (6 configs × 3 seeds, ~20–40 min)
python src/w3/train.py --sweep

# 4. Evaluate the best agent vs. all baselines on 100 test states
python src/w3/evaluate.py

# 5. Generate figures and LaTeX tables
python src/w3/make_report_assets_w3.py

# 6. TensorBoard
tensorboard --logdir runs/workshop3 --port 6006
```

Google Colab: open `notebooks/workshop3_colab.ipynb` and run all cells.

## 10. Notes

- Training is CPU-based. Approximate times: W1 baselines ~30 s; W2 LSTM ~3 min (40 epochs); W3 full sweep ~20–40 min; W4 full sweep ~10 min.
- Accuracy is not a decision metric for W1/W2: a constant "safe" predictor already reaches 94.5 %. Use Recall and PR-AUC.
- The DQN checkpoint is the best *validation* checkpoint, not the final one (DQN can degrade after peak performance).
- All result files are committed under `runs/` so the notebooks can be executed without retraining by setting `RETRAIN = False`.
