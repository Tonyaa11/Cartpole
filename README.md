# CartPole Machine Learning Project: Workshops 1–3

## 1. Overview

This repository contains Workshops 1, 2, and 3 of the Machine Learning course (Semester 2026-III, Universidad Distrital Francisco José de Caldas). The project centres on the CartPole-v1 environment and progresses from failure *prediction* (W1 & W2) to failure *avoidance* (W3).

**Workshop 1** covers dataset verification, exploratory data analysis, a leakage-free preprocessing pipeline (episode-level split), three supervised baselines (Logistic Regression, Random Forest, Gradient Boosting) and reproducible experiments with fixed seeds.

**Workshop 2** adds a deep learning model: an LSTM that reads a window of the last 16 steps of each episode, trained with position-weighted BCE loss, AdamW, cosine learning-rate schedule, dropout, weight decay, gradient clipping and early stopping. Training is logged to TensorBoard and CSV, the best checkpoint is saved to `checkpoints/model_best.pt`, and the test results are compared against the Workshop 1 baselines.

**Workshop 3** formulates CartPole control as an MDP and trains a Deep Q-Network (DQN) from scratch in PyTorch. A hyperparameter sweep over 6 configurations × 3 seeds is run; the best agent is evaluated against five baseline policies (including the Workshop 1 classifier used as a controller) on 100 held-out initial states, in both nominal and noisy conditions.

**Group:** 5 | **Authors:** `Miguel Angel Torres Ramirez, Cristian David Romero Gil, Omar Esteban Peña Sanchez`

| Dataset property | Value |
|---|---|
| File | `data/raw/cartpole_dataset.csv` (1.99 MB) |
| Rows / episodes | 35,874 / 400 |
| Columns | `episode, t, x, x_dot, theta, theta_dot, action, label` |
| Class balance | 94.51 % class 0 / 5.49 % class 1 (17.2 : 1) |
| SHA256 | `ec067d5dcc498f2b5c5486d24f290283431ef3a0db0a4952cfde84f07e4f53f8` |

Dataset provenance: generated by rolling out CartPole-v1 (OpenAI Gym 0.26.2) with a mixed policy (noisy expert + random actions); all seeds (Python, NumPy, Gym) are fixed to 42. A state is labelled `1` if the episode physically fails within the next five steps (|theta| beyond 12 degrees or |x| > 2.4). CartPole-v1 is free and pip-installable, with no license restrictions for this use.

## 5. Running Experiments

Run every command from the repository root.

### 5.1 Verifying the Dataset

```bash
python dataset_info.py
```

This will:

* Verify the SHA256 checksum (it must print `OK (matches expected)`)
* Print the shape, column types, missing values and duplicates
* Print class counts, imbalance ratio, feature ranges and episode statistics

---

### 5.2 Creating the Train / Validation / Test Split

```bash
python src/dataset.py
```

This will:

* Split the 400 **episodes** (not rows) into 70 / 15 / 15 %, stratified by episode length
* Save the partition in `data/splits.json` (279 / 61 / 60 episodes, seed 42)

The file is already included. Never re-split randomly: every script loads this file.

---

### 5.3 Training and Evaluating the Baselines

```bash
python src/baselines.py
```

This will:

* Build the 16 engineered features and standardise them (statistics from the training set only)
* Train Logistic Regression, Random Forest and Gradient Boosting
* Select the decision threshold on the validation set (maximum F1)
* Print precision, recall, F1, ROC-AUC, PR-AUC, accuracy and the confusion matrix on the test set
* Store the results in `runs/baseline_results_base.csv` and `.json`

## 6. Workshop 2: Deep Sequence Model (LSTM)

All commands below run from the repository root and reuse the **same episode split** (`data/splits.json`) and the same test rows as Workshop 1, so the metrics are directly comparable.

### 6.1 Model Architecture Check

```bash
python src/model.py                 # forward-pass smoke test (LSTM + GRU)
python src/model.py --cell gru --bidirectional --input-size 16
```

Prints the output shape and the parameter count of the architecture (default: 2-layer LSTM, 64 hidden units, MLP head → 53,569 parameters).

---

### 6.2 Training

```bash
python src/train_lstm.py                                  # default: LSTM, window 16, raw features
python src/train_lstm.py --cell gru --window 16           # GRU variant
python src/train_lstm.py --window 32                      # longer history
python src/train_lstm.py --hidden 128                     # wider model
python src/train_lstm.py --features engineered            # 16 engineered features per step
python src/train_lstm.py --augment                        # noise augmentation (train only)
```

This will:

* Build past-only sliding windows of the last `--window` steps (one sample per raw row; short episodes keep shorter windows, the packed RNN masks the padding)
* Standardise the features with statistics computed **on the training partition only**
* Train with position-weighted BCE loss (17.2:1 imbalance), AdamW, cosine LR schedule, dropout, weight decay, gradient clipping and early stopping on validation F1
* Log every epoch to TensorBoard (`runs/tb/<run>`) **and** to `runs/train_log_<run>.csv`
* Select the decision threshold on the validation set (maximum F1) and save the **best** model to `checkpoints/model_best.pt` (weights + scaler + threshold + config)
* Print the test metrics and store them in `runs/train_summary_<run>.json`

To watch the live curves:

```bash
tensorboard --logdir runs/tb
```

---

### 6.3 Test-Set Evaluation and Comparison with Workshop 1

```bash
python src/evaluate_lstm.py
```

This will:

* Reload `checkpoints/model_best.pt` (no retraining) and rebuild the same test windows
* Report accuracy, precision, recall, F1, ROC-AUC, PR-AUC and the confusion matrix at threshold 0.5 and at the validation threshold
* Print a comparison table: the three Workshop 1 baselines vs. the Workshop 2 deep model
* Save `runs/eval_<run>.json` and `runs/comparison_<run>.csv`

## 9. Reproducibility

All experiments are reproducible due to:

* Fixed random seed: 42 (`random`, `numpy`, `torch` and every scikit-learn model)
* A saved episode-level split in `data/splits.json`, which stores the SHA256 of the dataset it was created from
* Normalisation statistics and augmentation computed on the training set only (no leakage)
* No information from the future in the features or the windows, and the time index `t` is not used

## 9. Workshop 3: Reinforcement Learning Agent (DQN)

See `workshop3/README.md` for the full run instructions.

### 9.1 MDP Definition

| Component | Definition |
|---|---|
| State | `(x, ẋ, θ, θ̇)` — 4 continuous values |
| Actions | `0` = push left (−10 N), `1` = push right (+10 N) |
| Transition | Cart-pole equations of motion, Euler step 0.02 s (identical to CartPole-v1) |
| Reward | +1 per step survived + optional potential-based shaping |
| Termination | `|θ| > 12°` or `|x| > 2.4 m`; truncation at 500 steps |

### 9.2 Hyperparameter Sweep Results (validation, best seed per config)

|---|---|---|---|

| lr 1e-4 | 497.1 | 5 450 | 17 410 |
| gamma 0.95 | 500.0 | 3 530 | 17 410 |
| weight_decay 1e-4 | 500.0 | 2 560 | 17 410 |

## 11. Notes

* Training is CPU-based. W1 baselines: ~30 s; W2 LSTM: ~3 min (40 epochs); W3 full sweep: 20–40 min.
* Accuracy is not a decision metric for W1/W2: a classifier that always predicts "safe" already reaches 94.5 %. Recall and PR-AUC are the key metrics.
* DQN degrades after reaching peak performance; the saved checkpoint is the best validation checkpoint, not the final one.
* Small differences between models are not conclusive: results come from one split and fixed seeds.
